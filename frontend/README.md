# `frontend/` — React SPA

Frontend do RMR: SPA React 19 + TypeScript (Vite + TanStack Router/Query).

## Características

- SPA responsiva: terminal de operação (oficina) + dashboards
- Operação sem mouse (leitor USB HID emula teclado)
- Consome a API do backend via HTTPS `/api`
