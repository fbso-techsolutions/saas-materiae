# ADR-012 — Stack da Onda 1-Must (MVP mínimo) (Java 25 + Quarkus · Compose interno · RLS · Keycloak)

| Campo | Conteúdo |
|---|---|
| **Data / Status** | 2026-10-19 · ✅ **Decidida** — gate de arquitetura 9/9 da Onda 1-Must (MVP mínimo) ([PENDENCY-0015](../../../../projects/PRJ-SUP-2026-0000-RMR/pendencias.md)) |
| **Contexto** | Últimas decisões do gate para abrir a Sprint 1: onde a Onda 1-Must (MVP mínimo) roda, com qual stack e sem violar os guardrails — **API-First**, **keyboard-first**, **zero dependências externas**, **LGPD**, entrega em servidor interno. O time é pequeno e a operação é da própria área. |
| **Decisão** | **Onda 1-Must (MVP mínimo) inteira (dev, homolog e prod) em Docker Compose no servidor interno**, com base: **Java 25 + Quarkus (GraalVM Mandrel)** · **PostgreSQL 17+ com RLS** (+ Flyway) · **React + TypeScript (SPA)** · **Keycloak auto-hospedado** · RabbitMQ · MinIO · nginx. **DOKS + Kong + Istio + Redis** ficam como **alvo SaaS (Onda 4 (Produto)/Onda 5 (Plataforma))** — fora da Onda 1-Must (MVP mínimo). `tenant_id` + **RLS desde a Onda 1-Must (MVP mínimo)** (estende [ADR-002](adr-002-rls-multi-tenant.md)); workflow em **tabela de configuração** (adianta [PENDENCY-0003](../../../../projects/PRJ-SUP-2026-0000-RMR/pendencias.md) — [ADR-003](adr-003-workflow-configuravel.md)); auditoria append-only; CI/CD trunk-based. |
| **Justificativa** | 1) **Zero dependências externas** exige tudo auto-hospedado — Compose entrega um deploy unitário auditável; 2) Mandrel (native) reduz memória/latência no servidor interno; 3) Java/Quarkus é backend corporativo maduro para integrações (API-First) e o time é de origem Java; 4) RLS desde a Onda 1-Must (MVP mínimo) evita refatoração de segurança depois (não é "acréscimo SaaS"); 5) trilhos de evolução (K8s/Kong/Istio/Redis) já decididos para Onda 4 (Produto)/Onda 5 (Plataforma) — sem reescrever a aplicação. |
| **Consequências** | Onda 1-Must (MVP mínimo) sem Redis gerenciado → cache/sessão no Compose (limitar uso); Istio/Kong só em Onda 4 (Produto)/Onda 5 (Plataforma) → sem *rate limiting* de mesh na Onda 1-Must (MVP mínimo) (usar nginx); recursos do servidor interno dimensionados para native-image no build; ENABLER-0001 (servidor) e ENABLER-0004 (RLS) nascem desta decisão. |
| **Alternativas rejeitadas** | **Spring/Modulith** — trocado por Quarkus (native + adequação à Onda 1-Must (MVP mínimo)); **K8s desde a Onda 1-Must (MVP mínimo)** — operação prematura vetada pelo guardrail de servidor interno; **Cloud pública desde a Onda 1-Must (MVP mínimo)** — LGPD + dependência externa; **Next.js no front** — ver [ADR-013](adr-013-frontend-spa.md). |
