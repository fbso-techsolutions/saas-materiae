# ADR-013 — Frontend da Onda 1-Must (MVP mínimo): SPA (Vite + TanStack) × Next.js

| Campo | Conteúdo |
|---|---|
| **Data / Status** | 2026-10-19 · ✅ **Decidida** (spike ENABLER-0009 — [guia §3](https://github.com/fbso-techservice/platform-standards/blob/main/standards/process/guia-invest-enablers-spike.md)) |
| **Contexto** | Última decisão aberta do gate de arquitetura (follow-up C4 do [checklist](../../../../projects/PRJ-SUP-2026-0000-RMR/prj-tecnico/checklist-arquitetura-onda-1.md)): qual framework de front antes de iniciar as 13 stories da Onda 1-Must (MVP mínimo). Guardrails do projeto: **API-First**, **keyboard-first** (operadores sem mouse), **entrega via Compose** (ADR-012, servidor interno, zero dependência externa + LGPD). |
| **Decisão** | **SPA com Vite + TanStack Router + TanStack Query** (CSR puro, React 19 + TS). |
| **Justificativa** | 1) **API-First preservado por construção:** sem Server Components/Server Actions, o browser só fala REST — a regra de negócio nunca migra para o lado do front (com Next, o bypass é conveniente e gradativo). 2) **Encaixe na Onda 1-Must (MVP mínimo):** `vite build` → estático → nginx no Compose (RAM ~0); Next self-hosted exigiria runtime Node.js sempre aceso no mesmo servidor do build Mandrel, e perderia ISR/edge — cloud de front (Vercel/Netlify) está banida (LGPD + zero deps). 3) **Time de 1 dev front:** React tradicional com TanStack (mental model estável) × paradigma RSC (fronteiras server/client, cache que mudou em 13→14→15) — velocidade > features do framework. 4) **Keyboard-first + E2E Playwright:** DOM determinístico, foco/atalhos sob controle total, sem flakiness de hydration. 5) **Consistente com a visão geral** ("SPA responsiva"). |
| **Consequências** | Sem SSR/SEO — **irrelevante** (ferramenta interna atrás de login). Bundle inicial exige code-splitting por rota (padrão nativo do TanStack Router; verificado em review de PR). Reabrir só se Onda 4 (Produto)/Onda 5 (Plataforma) exigir portal público — como **outro app/camada**, contrato REST permanece. |
| **Alternativas rejeitadas** | **Next.js 15 (SSR/RSC)** — furaria o guardrail API-First e a topologia Compose; sem cloud de front, é Next degradado. **Next com `output: 'export'`** — SPA pior: paga as convenções do Next e abre mão do que o justifica. |
| **Rastreio** | R1–R5 (login/teclas), R20–R37 (operação sem mouse) · [ENABLER-0009](../../../../projects/PRJ-SUP-2026-0000-RMR/prj-tecnico/enablers/ENABLER-0009-decisao-stack-front.md) (spike) · [Sprint 1 §2](../../../../projects/PRJ-SUP-2026-0000-RMR/prj-produto/sprints/sprint-1-fundacao.md) · follow-up C4 do [checklist](../../../../projects/PRJ-SUP-2026-0000-RMR/prj-tecnico/checklist-arquitetura-onda-1.md) |
| **Assinatura** | Tech lead (Francisco Oliveira) + Eng front (Manoel Carlos) · **evidência executável:** scaffold no Compose até 21/10 (DoD do ENABLER-0009) |
